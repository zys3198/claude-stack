# 维护说明

本文件维护 `skill-auditor-by-user` 的审计、设计和验证规则；主文件负责运行时执行，本文件负责证据源、同步文件和变更门禁。

主文件路径：`SKILL.md`

## 何时必须更新

| 触发信号 | 必做动作 |
|---|---|
| Skill frontmatter、触发机制或配套文件惯例变化 | 复核通用十查和对应类型追加检查 |
| 审计实战发现漏判、误判或运行时假完成 | 把真实事故写进 CHANGELOG，再改检查项 |
| 官方 skill 规范或宿主运行时变化 | 复核 description、输入输出、验证和模型解耦规则 |
| 新增 router、executor 或 reference 类型 | 补类型边界、正负触发和组合场景 |
| 来源、插件、同步或迁移机制变化 | 更新来源审计证据链，不凭目录推断归属 |

## 证据顺序

1. 当前会话可用 skill/tool/agent 清单。
2. 本机目标文件、宿主文件、安装台账和插件 payload。
3. 官方文档、官方包元数据和真实源码。
4. 实际运行输出、失败复现、动态基线和用户确认。
5. 证据不足时标记“不确定”，不拍脑袋补规则。

Memory 只提供历史背景，不证明当前 skill 可用；迁移路径不证明自建归属。

## 变更门禁

- 增删检查项、触发词、路由条目或严重性标准，必须引用真实事故、官方变更或失败测试。
- 只做机械版本戳或维护记录补齐，可不跑动态基线，但必须记录跳过理由。
- description、正向触发词、负向边界、输入输出契约或宿主接线变化，必须跑动态场景。
- 新 skill 先做不用 skill 的反向测试；已有能力稳定覆盖时，不新建。
- 审计库级留删、冷热分级时交给 `skill-trimmer-by-user`，不在本 skill 内执行删除。
- 路由目标必须经过当前可用性和来源核验；同名不等于同源，哈希相同也不等于可直接删除。

## 证据分层

每条结论标注证据类型：

- `静态`：文件、frontmatter、引用、目录和配置。
- `运行`：加载、调用、输入输出和真实触发结果。
- `使用`：实际任务是否解决问题；没有数据写“不可用”。
- `确认`：用户对技术选型、权限、删除、外发或范围的明确决定。

## 根入口减量方法

本节只在执行或验证根入口减量时读取；入口保留路由、完成标准和安全门禁，分支细节通过本目录已有 references 或 scripts 按条件披露。

### 测量对象与信息层级

分别记录：固定注入（CLAUDE.md/AGENTS.md）、路由描述（name + description）、调用正文（SKILL.md）和按需材料/工具回流；未读取的 references、scripts、测试和模板只占磁盘，不冒充本次上下文成本。每段只归一个层级：根入口步骤、根入口参考或分支参考。只有部分分支使用的内容下沉到 reference，并留下 context pointer。

每条 pointer 必须说明：何时读取、其中包含哪些会改变判断/执行/验收的内容、读取是必须还是可选。权威位置只保留一份；环境一眼可查的信息指向权威来源，安全、权限、业务和验收约束不能因减量削弱。

### 减量流程

1. 记录目标路径、调用方式、改动基线、入口行数/字节数、引用、测试和行为合同。
2. 列出运行分支；所有分支共同需要的内容留在入口，分支专用内容原样迁入本 Skill 的已有 references。
3. 按 `duplication`、`sediment`、`relevance`、`no-op` 逐句检查；先删解释性铺陈，保留做多深、何时停止和失败报告。
4. 保留可观察的完成条件、等待理由、`passed` / `failed` / `blocked` / `not-run` 状态、用户确认和失败修复/重新验证门禁。

### 行为等效与输出

静态变短不等于效果不变。用同一模型、宿主、工具和运行参数比较正向、负向、缺输入及兄弟 Skill 撞词场景；按 target → guardrail → holdout 顺序检查，无法观测实际加载上下文时写 `not-run`。比较任务结果、关键判断、门禁、产物和失败状态，不要求逐字一致。

减量审计报告至少包含：对象与调用方式；改前/改后行数和字节数及测量等级；分支表；保留内容；原位置到 reference 的迁移与 pointer 条件；删除项及行为证据；安全/权限/业务/验收门禁；baseline、candidate、target、guardrail、holdout 的真实结果；`blocked`、`not-run` 或待用户确认。缺少运行证据只能交付静态候选和测试计划，不能宣称效果不变。
