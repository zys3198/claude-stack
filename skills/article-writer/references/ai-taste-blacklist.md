# AI 味避坑清单

本文件从 [De-AI-Prompt-Enhancer-Writer-Booster-SKILL](https://github.com/OUBIGFA/De-AI-Prompt-Enhancer-Writer-Booster-SKILL) 仓库提炼，并结合本 skill 覆盖的多种技术文体做了适配。

用途：写作完成后的终稿扫描参考，不是写作过程中的约束。命中不代表必须改——要看文体是否适用。

---

## 一、词汇层（高频 AI 词）

### 1.1 路标词 / 填充短语

这些词的功能是"告诉读者我要说什么"，但读者不需要被导航。

| AI 味词汇 | 替换方向 |
|-----------|---------|
| 综上所述、总而言之 | 直接删，或换成具体结论 |
| 值得一提的是、需要指出的是 | 直接说那件事，不用引导语 |
| 换句话说、简而言之 | 删掉引导语，用更清楚的方式直接重述 |
| 与此同时、在此背景下 | 删掉，靠内容逻辑自然过渡 |
| 不可否认、毋庸置疑 | 直接删，或给出证据后让读者自己判断 |
| 在某种意义上、从某种角度来说 | 要么限定清楚，要么删掉 |
| 总的来说、总体而言 | 删掉，直接给结论 |

### 1.2 宣传腔 / 空泛修饰词

| AI 味词汇 | 替换方向 |
|-----------|---------|
| 赋能、助力、打造、构建 | 说清楚具体做了什么 |
| 引领、驱动、卓越、革命性、颠覆 | 给具体功能、限制、条件、代价 |
| 显著提升、大幅优化 | 替换为具体数字或删掉 |
| 深刻揭示了、充分体现了、具有重大意义 | 给事实，让读者自己感受意义 |
| 不可或缺、至关重要 | 说为什么重要，或删掉 |
| 全方位、生态、格局、蓝图、矩阵 | 说具体的组件和关系 |
| 从 X 走向 Y | 说具体发生了什么变化 |
| 严谨/严密/精准/审慎/克制/沉稳 | 挂在可核对对象上才保留（"严密的论证"后真有论证），挂在空对象上一律删 |

### 1.3 伪学术腔

| AI 味词汇 | 替换方向 |
|-----------|---------|
| 底层逻辑、顶层设计 | 说具体机制 |
| 赛道、闭环、抓手、红利 | 说具体的业务场景和操作 |
| 舆论场、话语场、博弈场 | 直接写"舆论""讨论""博弈" |
| 宏大叙事、官方叙事、主流叙事 | "说法""论调""口径" |
| 认知升级、降维打击、范式 | 删掉或换成具体描述 |
| 路径依赖（非经济学语境） | 说具体的历史原因 |

### 1.4 伪口语化高频词

这些词模拟"亲切拆解"语感，是 LLM 对齐阶段形成的语言偏好。

| AI 味词汇 | 替换方向 |
|-----------|---------|
| 拆一拆、盘一盘、聊一聊、捋一捋 | 删掉引导语，直接说 |
| 拆解、梳理、剖析、解构 | 改为"看""说""讲"或直接省略 |
| 聚焦、洞察、深耕 | 删掉，直接进入正题 |
| 划重点、敲黑板 | 删掉，直接给信息 |
| 说白了、本质上、归根结底 | 后面接的东西如果真简单就删引导语；如果复杂就别装简单 |
| 简单来说、一句话概括 | 如果真能简单说就简单说，不用说"简单来说" |
| 换个角度看、从某种意义上说 | 删掉，直接给出那个角度的内容 |

### 1.5 AI 高频隐喻（比喻义）

以下词的**比喻义**是 LLM 统计高频输出，命中率极高。**字面义不受限**（比如真实的账本、真实的成绩单可以写）。

| 隐喻词 | 问题 |
|--------|------|
| 噪音/信号 | 把复杂判断简化为二元筛选 |
| 底色、光谱、滤镜 | 空泛的视觉隐喻 |
| 解药、土壤 | 把抽象关系包装成物理隐喻 |
| 拼图、镜像 | 把复杂系统包装成简单物件 |
| 路径、窗口 | 万能导航隐喻 |
| 缩影 | 把个案强行拔高为代表 |
| 账本/成绩单/清单 | 把复杂问题包装成可结算、可打分、可勾选的对象 |

### 1.6 伪坦率 / 伪严谨评价词

| 类型 | AI 味词汇 | 问题 |
|------|----------|------|
| 伪坦率 | 直白/坦白/坦率/赤裸/不加掩饰 | 替读者贴"坦率标签"，让事实自己说话就好 |
| 伪严谨 | 严谨/严密/精准/审慎/克制 | 模拟"知识分子冷静感"，空挂在无对象句子上就是冗余 |

## 二、句式层（模板句式）

### 2.1 二分对照壳

**信号**：不是 A 而是 B / 并非 A 而在于 B / 不在于 A 而在于 B

这类结构看似深刻，读感却整齐得像模板。连着出现两三次，读者就会意识到在套壳。

**修法**：
- 改为不对称让步："A 固然……；但……"
- 直接说 B，把 A 放到插入语或从句里
- 直接下判断，不搞对仗

### 2.2 条件/因果/全称过度标记

AI 倾向于给每个逻辑关系都套一个工整的关联词对，而人类更常用隐性逻辑。

| 过度标记的句式 | 密度阈值 | 替换方向 |
|--------------|---------|---------|
| 一旦……就…… | 全文合计 <= 2 | "要是/若/倘……便/也就"或直接铺事实 |
| 只有……才…… | 同上 | 缩小范围后断言 |
| 无论……都…… | 同上 | "在……这件事上"或"哪怕"让步 |
| 随着……的发展/推进 | 同上 | 删"随着"，直接给时间节点或事实 |
| 正是因为……所以…… | 同上 | "之所以……是因为"或直接铺因果 |
| 通过……来…… | 同上 | "靠/凭/用"或直接嵌入语流 |

### 2.3 极值判断句式

**信号**：最残酷的地方在于 / 最可怕的是 / 真正……的是 / ……之处在于 / 更……的是

制造"别人没看到的真相"的戏剧感，密度超过 1 次就是堆叠。

**修法**：删掉极值框架，直接给事实和判断。一组数据比"最残酷的地方在于"更有杀伤力。

### 2.3.1 戏剧化揭露修辞

**信号**：扯下遮羞布 / 撕下面具 / 剥开外衣 / 揭开真面目 / 戳穿谎言

这是 LLM 批判类文本的签名句式。默认清零。

**修法**：直接给事实和判断。"扯遮羞布"能做到的，一组数据或一段引文做得更好。

### 2.4 定义式/判断式堆叠

**信号**：A 是 B / 所谓 A 即 B / A 就是/意味着/可以概括为 B / 必然/显然/绝对 + 判断句

把复杂判断压缩成字典条目，看似权威实则空洞。全文 <= 3 处，每处必须有事实支撑。

**修法**：改为动作或事实描述（"A 在做 X"），改为场景还原（"碰上 A 时，常见做法是……"）。

### 2.5 句尾虚假深度补语

**信号**：句尾频繁出现"从而……、进而……、以此……、确保……、彰显……、反映……、为……奠定基础"

**修法**：改成可见动作与代价：谁做了什么、导致什么。没有凭据就删掉那半句。

## 三、结构层（骨架问题）

### 3.1 三段式过度使用

任何地方都要凑三项：A、B、C；既…又…还…；首先其次最后。

两项优于三项。若确有三层推进，把其中两层合并进长句，用分号织起来。

### 3.2 挑战与展望模板段

单独一段写"挑战与机遇并存 / 未来仍需努力 / 展望未来 / 仍有提升空间"。

默认删。真要写未知，就写具体的不确定：哪两条约束卡住、哪一步最难验证。

### 3.3 鸡汤式收尾

"未来可期 / 拭目以待 / 我们有理由相信 / 光明前景 / 这只是开始"。

用冷判断、事实或引文收束。若只能写"乐观"，说明前面论证没写够。

### 3.4 模糊归因

"专家认为 / 研究表明 / 有人指出 / 普遍认为"却不给来源。

给一个可核对的"某年某月某报道/某场合原话"；无来源就降级为"常见/不少"等限定表述。

### 3.5 协作交流痕迹

"让我们 / 接下来我们将 / 本文将 / 希望这能帮助你 / 下面我会 / 先来看"。

删掉"对读者说话"的引导句，直接开讲。

### 3.6 步骤承接过渡（最隐蔽）

**信号**："把 X 做完/说完/看完/理完/弄清/厘清，再/便/就 Y"

这种"我刚完成了一个分析步骤，现在进入下一步"的过渡，是 LLM 最难自动避免的痕迹之一。

**修法**：删掉前半句，直接从新段落的事实或判断起笔。

### 3.7 章节篇幅完全均匀

报数本身没问题（"目前开放了 3 种接入方式"），但报完数后每节都凑成同等长度就是问题。重要的写 5 段，次要的 2 句话带过。

### 3.8 评语式判词与套话否定壳

以下四类正文清零，逐字引文除外：

① `X + 很/非常/相当 + 清楚/明显/简单/直接/残酷/难听/刺耳/尴尬/讽刺`，以及 `X + 说得/写得/摆得 + 很 + 清楚/明白/直白/难听`（如"方舟子在自序里把书的方向说得很清楚"）

② `X + 不吃/不信/不认/不买 + 这一套/那一套/这套说法/这套逻辑`（如"《批评中医》不吃这一套"）

③ `X + 没有跟着/绕开/跳出/摆脱/拉回 + 站队游戏/身份叙事/文化标签/话题陷阱/争论框架`（如"绕开站队游戏"）

④ `X 的 + 地方/问题/麻烦/难处/关键/要害/症结 + (在于/是/正在这里/也正在这里)`，尤其禁止和"难听/刺耳/清楚/麻烦/尴尬"搭配

**修法**：不要换同义词逃逸，直接写具体动作、证据、后果或判断。把"说得很清楚"改为原话或具体主张，把"不吃这一套"改为对象实际做了什么。

### 3.9 段落同构模板

连续 3 段以上都呈现"第一句提出小论点/判断，随后解释或举例，最后一句收束成一句可摘抄结论"的结构，即判为高 AI 味，即使词表没有命中也必须重写。

**修法**：不是替换段首词，而是改变信息进入方式——有的段落从场景、事实或反驳对象切入；有的段落只承接上一段继续推进，不另起小论点；有的段落用短句停顿，不承担完整论证；有的段落在中途换气，不强行段尾总结。禁止把"问题是/关键是"换成"核心在/说到底"来逃逸。

### 3.10 段落厚度均质化

5 段以上正文中超过 70% 段落长度落在同一窄区间（如 140-220 字），且每段都承担一个完整论点，判为说明书化。

**修法**：按阅读节奏重排——允许 40-80 字短段、120-180 字中段、220-350 字厚段交替。短段必须是真停顿、转折、反讽或余味，不得写成路标句；厚段要有事实链或语气推进。

### 3.11 段尾金句化收束

连续段落都以抽象判断（"病人买单/风险转嫁/不能带过去/并不够用"等）收尾，判为 AI 总结腔。

**修法**：收尾不必每段都有；能停在事实、场景、引语、具体后果上的段落，不要再补一句概括。全文只允许 1-2 处明确收束句，且必须服务于文章尾声或强转折。

## 四、排版层

### 4.1 粗体过度

正文里频繁加粗强调，或加粗 + 冒号做小标题。

加粗只保留关键词、关键数字或一句核心判断。

### 4.2 冒号当提纲符号

"概念：解释" "问题：答案"连发。

冒号只用于直接引语提示语，其余场景用逗号、分号或拆句。

### 4.3 刻意换词（同义词循环）

同一概念反复换不同词（提升/增强/优化/改善）以显得"丰富"。

选一个最准确的词重复使用。重复不可耻，含糊才可耻。

### 4.4 表情符号

正文中出现 🙂🔥✅ 之类。除非原文风格明确允许，否则全部删除。

### 4.5 破折号过度使用

AI 特别喜欢用"——"制造停顿感和"高级感"，经常每段都用同一种插入方式，或者把破折号当条目符号。

**信号**：
- 每段都用"——"做插入说明或转折
- 把破折号当列表分隔符用（"要点一——XXX / 要点二——XXX"）
- 连续两段以上都用破折号做段中注释

**密度建议**：1500-3000 字正文，破折号控制在 3-5 个以内。超过 5 个要检查是否在当模板用。

**修法**：
- 破折号该用于解释、转折、补充或制造真正的停顿时才用
- 如果只是为了"看起来更高级"或替代正常标点，改用逗号、分号、括号或直接拆句
- 把破折号里的内容拎出来独立成句，或者用逗号平铺

### 4.6 引号过度使用

AI 爱用引号做"强调""反讽""定性"和"包装术语"，结果就是满篇引号，读起来像在给每个词加空气引号。

**信号**：
- 给普通概念加引号（"智能化""数字化转型""降本增效"）——不是引用，只是在暗示"你懂的"
- 大量用引号做反讽标记（这个"创新"那个"优化"）——偶尔用没问题，连着用就成了腔调
- 把不可追溯的定性、口号、文件措辞塞进引号冒充"原话"
- 每段都有加引号的词

**密度建议**：引号用于直接引用原话、特定术语首次出现时标注、以及真正的反讽。1500-3000 字正文，引号出现次数控制在 5-8 处以内（不含代码块和正常术语标注）。反讽引号全文不超过 2 处。

**修法**：
- 不是真引用就去掉引号改成转述
- 强调靠措辞和语序，不靠加引号
- 反讽偶尔用一次有力，连着用就变味
- 术语首次出现标注后，后续不再加引号
