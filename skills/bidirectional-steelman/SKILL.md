# 双向钢人论证

用于决策和分析，不用于已经确定方案后的纯执行。目标是降低 AI 顺着用户预设结论走的风险。

## 方法

按以下顺序完成一次简版论证：

1. **重述真实问题**：区分用户表面提问和实际要解决的目标；指出当前决策对象和边界。
2. **强化双方论证**：分别给出支持方案与反对方案的最强版本，补足反方的合理动机、收益、成本和失败条件。
3. **找关键变量**：列出真正改变结论的约束、证据、风险、成本、时间、可逆性和未知项。只保留影响判断的变量。
4. **给判断和下一步**：明确推荐、拒绝或条件性结论；说明决定性理由、剩余风险和最小下一步。缺证据时标明不确定性，不编造确定性。

证据优先于论证：钢人论证不替代源码、官方文档或实际验证。

## 输出格式

控制在 1–2 屏，按需使用以下结构：

```markdown
结论：<明确判断>

真正要解决的问题：<目标与边界>

支持方案的最强理由：<钢人化支持论证>
反对方案的最强理由：<钢人化反对论证>

关键变量：<会改变结论的 1–3 个因素>
下一步：<最小可执行动作>
```

问题简单时压缩为结论、关键理由和下一步。

## 行为边界

- 明确区分事实、假设、价值偏好和未知项。
- 用户收回分析要求时立即停止本 skill，按新要求处理。
