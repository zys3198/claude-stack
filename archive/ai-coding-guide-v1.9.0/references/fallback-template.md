# 跨域兜底反问模板（共享）

三 router 型 guide 共用本模板，由 `ai-coding-guide` Step 4 提炼。其他 guide 在「无匹配/分类不清」时引用本文件，不在各自 SKILL.md 重复展开。

主文件路径：`SKILL.md`

---

## 第一问：四大方向

- A: 写代码（编码域 → ai-coding-guide）
- B: 看代码（编码域 → ai-coding-guide，分类「理解代码/审查代码」）
- C: 修问题（编码域 → ai-coding-guide，分类「调试 bug/构建错误」）
- D: 非编码交付或独立工具请求（对外内容 → article-writing-guide / 学习结果 → learning-guide / 视觉产出 → ai-coding-guide 前端视觉子路径 / **仅需直接回答或调用独立工具 → 直接执行，不制造第四 router**）

**按方向转介对应 guide 后，第二问由该 guide 的路由表收口。**

---

## 适用：本模板的「兜底」含义

| 触发 | 动作 |
|---|---|
| 用户信号命中两个或以上 guide 域（多域重叠） | 走本模板第一问，让用户定主域 |
| 用户信号完全不在三域枚举内 | 走本模板第一问 D 分支：按最终交付物归属三域，或独立工具请求直接执行（不设「其他→自由文本」空洞兜底） |
| 用户信号在本域内但分类仍模糊 | 直接走本 guide 的路由表 Step 1 信号匹配，不要再用本模板 |

**不要**：
- 拿「其他/任何/等等」等范畴词兜底（依据：Superpowers #1301 范畴词被放大解释）
- 在三个 guide 各自 §「路由失败兜底」重复写完整四问——统一引用本文件

增删本模板问题前必须引用真实误路由事故或官方变更证据，否则保持原样（防无证据漂移）。
