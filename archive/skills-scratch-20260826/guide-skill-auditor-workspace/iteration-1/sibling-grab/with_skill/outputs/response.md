### 动态基线（本请求**必跑**，静态查不出抢单）

触发条件满足两条：兄弟域高频词重叠 + 域边界条款存疑。造 3-5 个边界 prompt 派子代理裸跑（只给 description）看第一跳：

- 纯写作请求（文章/教程/博文）→ 看第一跳是否被 ai-coding-guide 抢走 → **P0 误路由**
- 纯编码请求 → 对照组，验证 ai-coding-guide 正常接单
- 模糊请求（如「帮我写个东西」）→ 看落到哪家、有无合理 fallback
- 点名下游 skill 场景 → 验证直达路径

每修一个边界 bug 后，在 **两 guide 各补一条镜像 test-prompt**（防单边回归断链）。
