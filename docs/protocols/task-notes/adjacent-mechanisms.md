# 与相邻机制的区别

本文件是 [`task-notes.md`](../task-notes/task-notes.md) 的下沉部分，只在与相邻机制边界不清时读。

- **什么时候写**：判据是压缩损失。自动摘要挑不出来的（为什么这么选、被否掉的路子、下一步、未决）在压缩或切换前落盘。可携带性不设门槛：换宿主、换目录或仓库、交给同事、分叉出独立支线照写，同宿主同目录的长任务同样写。
- memory：跨会话长期事实，跟着用户走；任务笔记是任务内的接续材料，任务结束后按「任务收尾后的处置」一节处置。
- **与另外两处不混同**：`docs/` 是给项目参与者读的正式文档，skill 的 `references/` 是给未来的 agent 读的规程；任务笔记是任务线内部的接续材料，跨会话累积，只给这条任务线的后继会话读。
- **执行纪律**：[`execution-discipline.md`](../execution-discipline/execution-discipline.md) 管行为（不许作弊、连败几次换项、不许停下来等），本协议管记录（未决写在哪、什么进、交付时带不带）。两边在「未决」这个词上共指一件事：纪律那边管它是阻塞项还是可跳过，本这边管它落成哪一行。
- compact：摘要挑「这段对话讲了什么」，笔记挑「下一个会话接手需要什么」。所以笔记不能等压缩时靠自动摘要代劳——「为什么这么选」和「下一步」只有当事人挑得出来。
- handoff：**会话结束时才产生的一次性产物**，一次会话一份，落在 `handoff/<日期>-<短名>.md`。判据是寿命——**只活到下一个会话的写这里**（现状快照、接着做什么、别踩什么、这次该调哪些 skill），**跨会话还要查的进单条笔记**（证据、结论、取舍、实测方法）。不复述笔记，只写路径；下一个会话开工时按入口的「最新交接」行找到它读一次，读完即可删。入口的「下一步候选」写这条线要做什么，handoff 只写怎么起手（从哪一节开始、先读什么、注意什么），两层不重抄。交接材料必须足以让后续 agent 在没有聊天隐式状态的情况下继续。
